Write a MongoDB aggregation query to list all students along with their department name using a join between students and departments.


db.students.aggregate([ 
{ 
   $lookup : {
  	from : "departments",
	localField : "deptCode",
	foreignField : "code",
	as : "studentDep"
	}
   },
   {
      $unwind : "$studentDep" 
   },
   {
      $project : {
           studentName : "$name",
	   studentDepartment : "$studentDep.name",
	   _id : false
	 }
   }
])

Join students with departments

Filter students with percentage greater than 80

Group them by department name

Count how many top performers (percentage > 80) are in each department

Sort the departments by that count in descending order

{ "_id": "Computer Science", "topPerformers": 2 }  ==> output
{ "_id": "Electronics", "topPerformers": 1 }  ==> output

==> code

db.students.aggregate([
  {
    $lookup: {
      from: "departments",
      localField: "deptCode",
      foreignField: "code",
      as: "temp"
    }
  },
  {
    $unwind: "$temp"
  },
  {
    $match: {
      percentage: { $gt: 80 }
    }
  },
  {
    $group: {
      _id: "$temp.name",
      topPerformers: { $sum: 1 }
    }
  },
  {
    $sort: {
      topPerformers: -1
    }
  }
])
